## 📖 Descripción del Proyecto

Este repositorio documenta mi progreso a través del curso **"100 Days of Code: The Complete Python Pro Bootcamp"** impartido por la Dra. Angela Yu en Udemy. 

El objetivo es dominar Python construyendo **100 proyectos prácticos** en 100 días, abarcando desde fundamentos básicos hasta automatización, desarrollo web, ciencia de datos y machine learning.



## 🛠️ Tecnologías y Herramientas Utilizadas

A lo largo de este reto, estoy aprendiendo y aplicando las siguientes tecnologías:

- **Lenguaje:** Python 3
- **Entornos:** PyCharm, Jupyter Notebook, Google Colab
- **Automatización y Web Scraping:** Selenium WebDriver, Beautiful Soup, Requests
- **Ciencia de Datos:** Pandas, NumPy, Matplotlib, Plotly, Scikit-learn, Seaborn
- **Desarrollo Web:** HTML5, CSS3, Bootstrap, Flask, REST APIs
- **Bases de Datos:** SQL, SQLite, PostgreSQL
- **Control de Versiones:** Git, GitHub
- **Despliegue:** GitHub Pages, Heroku, Gunicorn
